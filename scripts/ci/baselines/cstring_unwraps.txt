# `CString::new(x).unwrap()` / `.expect(..)` where `x` is not a provably-safe literal.
#
# `CString::new` fails on interior nul bytes and nothing else, so when `x` is caller-supplied the
# unwrap is a panic safe code can trigger from outside the crate. Measured 2026-10-18 by
# scripts/ci/cstring_unwraps.py: 66 fallible conversions in the hand-written sources, 10 of them
# on literals with no `\0` escape (those cannot fail, so they are not debt), leaving **56 sites
# across 23 files** as the register below. Two independent measurements agreed on 56/23 before this
# ledger was recorded (the ruler and a throwaway paren-matching script), which is the only reason
# the number is worth writing down.
#
# This is a debt register, not a target line: the comparator judges both directions, so a new site
# is red, and so is fixing one until the ledger is re-recorded downward. The direction is 0.
# Two forms are already paid back and must not come back: `close()`'s debug string truncates at the
# first nul instead (`src/networking_sockets/connection.rs`), and `http.rs` / `html_surface/mod.rs`
# route through a `cstr()` that answers `InvalidParameter`.
# Re-recorded the same day for the first payment: 11 of the 56 are gone (all 10 fire-and-forget
# setters in src/server/config.rs plus set_connection_name), leaving 45 across 21 files. Both files
# left the ledger entirely, which is the direction the register exists for. The rule they moved to
# is `c_string_prefix` in src/utils/strings.rs, and `debug_string_prefix` in
# src/networking_sockets/connection.rs now delegates to it instead of keeping its own copy -- one
# rule, one implementation.
# Re-recorded immediately after: the ruler now drops file-scope `#[cfg(test)]` modules, using the
# same scoping rule api_coverage.py already applies (imported, not reimplemented). That removed one
# record -- src/input/origins.rs's `CString::new(vec![b'a', 0xff, b'b']).unwrap()` is a test choosing
# a fixture, not a caller-triggerable crash -- so the register is 44 across 20 files.
# Re-recorded again for the second payment: 13 more sites gone (friends/friend.rs, friends/overlay.rs
# x4, matchmaking/mod.rs x2, timeline.rs x4, user_stats/leaderboard.rs x2), so the register is 31
# across 17 files. Every one of those methods returns nothing -- no channel to answer through --
# which is what makes cutting at the first NUL the faithful choice rather than a swallowed error.
# Of the 32 fallible conversions left in non-test code, exactly 1 is an infallible literal
# ("Handle was dropped" in NetConnection::drop), and no site is inside a #[cfg(test)] module any
# more: the ruler blanks file-scope test modules through api_coverage.strip_test_modules, which had
